# NOVARQ MARKET — pre-launch website

This repository contains a static HTML presentation website for NOVARQ MARKET.

## Files
- `index.html` — website entry point.

## Current scope
- Navy, gold and white visual identity retained from the existing NOVARQ MARKET draft.
- 22 approved main product categories.
- French, English and Arabic interface translations currently included.
- Partnership inquiry form opens the visitor's email application using `mailto:`. The website does not store submissions.
- No checkout, cart, payment processing, seller accounts, product inventory, or order management is implemented.
- Italian, Turkish and Chinese are planned language options but are not implemented in this build.

## Before publishing
1. Keep a separate backup of the currently live Cloudflare website.
2. Review the contact email in `index.html` and replace it only with an address you control.
3. Test the page on mobile and desktop.
4. Connect this repository to Cloudflare only after confirming the repository contents.

This is a pre-launch static catalog/contact page, not a functioning multi-vendor marketplace.
